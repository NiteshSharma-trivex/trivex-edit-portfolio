# TRIVEX EDIT — V4

Premium responsive video-editor portfolio for TRIVEX EDIT.

## Included
- Cinematic black/red UI
- Responsive mobile navigation
- Scroll reveal animations
- Scroll progress indicator + active navigation
- 3 real YouTube Shorts with thumbnail previews
- Click-to-preview YouTube modal
- Services, process, about and contact sections
- Email CTA: shaurya121518@gmail.com
- No build tools required

## Run locally
Open `index.html` in a browser.

## Deploy free
This is a static site. Upload the contents of this folder to a static host such as GitHub Pages, Netlify or Vercel. Keep `index.html` at the site root.

## Before publishing
1. Replace the YouTube/Instagram URLs if you have your exact social profiles.
2. Replace any placeholder text with your final client-facing copy.
3. Test the contact email and all project links on mobile.
